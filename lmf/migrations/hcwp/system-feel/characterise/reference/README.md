### Infrastructure doubles (actual, not proposed)

- `Compatibility.cs` supplies minimal DTO/entity shapes consumed by extracted expressions; unneeded members of original DTOs are not fabricated. JSON data is deserialised to fresh objects for every request. Raw history rows retain extra saved metadata via JsonExtensionData; no save, update, duplicate/repeat recalculation or measurement-date-overwrite claim is made. Those remain baseline rules.
- `UnitOfWork.Repository<ChildLocations>` supplies only synthetic authority rows; AsNoTracking is an identity function. Source SingleOrDefault and predicates execute as LINQ-to-Objects. ResultService reconstructs patient, examination description type and given-date navigation from stored flat fixture rows, then executes source filter/order; saved row mapping is identity read-back, not full EF/AutoMapper mapping validation. No SQL translation, DB constraints/transactions/concurrency/collation/order or EF6/Oracle parity claim.
- `Program.cs` records DefaultAccessForChild as an excluded no-op dependency call. Access-control/session/remote-record decisions, WCF hosting/fault transport, appointment/recall and operational lookup directories are not exercised. Missing graph members cause failures, not assumed operational defaults.
- `Resource.Format` returns an identity and argument object; CurrentStatusText and EnumResolver are similarly observed requests. Actual legacy resources remain unavailable (SF-G01/G02). Symbolic centre/status constants do not recover numeric identities. These adaptations need reviewer acknowledgement before human approval.
- `run.py` resolves fresh fixture graphs before invoking C#. It never sends `expected` into the runtime. It sends mixed, unfiltered histories (or reverses the entire input when requested). The explicit KD03-only adapter runs AFTER the original all-KDP query/delegate. This is slice scope, not a rewritten legacy service predicate.
- Recursive subset comparisons are strict about types, null, strings, booleans and list cardinality. The special ID comparator consumes complete multisets, and date groups consume every observed row without asserting within-tie order. Physical/facet inputs are returned and checked unchanged.
- **Intentional seed-authored facets**, isolated in Program.cs: Recorded/Not examined from saved reason presence, Initial/Repeat from persisted bool, and Has concern from applicable Heart/Hips/Eyes/Testes/PhysicalGeneral raw value 2 only. No persisted aggregate status is created. These predicates are labelled as enhancements in scenario evidence, not original aggregate clinical logic. No filters, paging, routes or target UI are implemented.
